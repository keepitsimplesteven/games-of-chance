# Tiebreaker Convention

Any and all tiebreakers, unless explicitly specified otherwise by the user, must use a fully balanced random decision. Never use alphabetical sorting, name-based ordering, or any deterministic method to break ties. Equal odds for all tied participants.

This applies to:
- Seeding order when players share the same rank/score
- Any gameplay situation where a tie must be resolved
- Any bracket or tournament pairing decisions among equals
